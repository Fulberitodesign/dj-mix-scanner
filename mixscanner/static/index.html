    🎵 Créer une playlist Spotify

    Méthode recommandée — gratuite, sans Premium :

    1. Cliquez sur « Copier la liste » (une ligne « Artiste - Titre » par morceau).
    2. Ouvrez TuneMyMusic (ou Spotlistr), collez la liste, connectez votre compte Spotify : la playlist est créée.
    ⚠️ à vérifier — Shazam a peut-être reconnu une reprise ou un remake au lieu du morceau joué. Écoutez ces passages et corrigez la liste si besoin avant de la coller :
      TuneMyMusic Spotlistr Télécharger (.txt)

      Autre méthode — liens Spotify à coller dans l'app : l'outil cherche le lien Spotify de chaque morceau (base MusicBrainz, ou API Spotify si vos clés sont configurées). Sans clé Spotify, les morceaux peu connus (remix, edits de DJ) sont souvent introuvables.

      1. Cliquez sur « Préparer les liens Spotify » (1 à 3 s par morceau, laissez la page ouverte).
      2. Cliquez sur « Copier les liens Spotify ».
      3. Dans l'app Spotify : + Créer → Playlist, cliquez dans la playlist vide puis faites Cmd + V.

      Connexion directe : l'outil crée la playlist lui-même sur votre compte (app Spotify avec Web API requise).
