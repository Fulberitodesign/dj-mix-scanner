Liens Spotify à coller dans l'app

L'outil cherche le lien Spotify de chaque morceau (1 à 3 s par morceau). Dans l'app Spotify : + Créer → Playlist, cliquez dans la playlist vide puis Cmd + V. Les remix et edits de DJ sont souvent introuvables : pour eux, préférez « Copier la liste » + TuneMyMusic.
